- 多平台，支持猫爪源（md5 源）
- 项目：[https://github.com/ant-video/ant-video/](https://github.com/ant-video/ant-video/)
- 频道：[https://t.me/ant_video](https://t.me/ant_video)

### 1.3 AinanPlayer（原名 CatPawPlayer，md5 源）
- PC 版猫爪源播放器
- 项目：[https://github.com/Ainanya21/AinanPlayer](https://github.com/Ainanya21/AinanPlayer)
- 频道：[https://t.me/AinanPlayer](https://t.me/AinanPlayer)
- 群组：[https://t.me/AinanPlayerChat](https://t.me/AinanPlayerChat)

### 1.4 tvs（md5 源）
- md5 接口壳，安卓和苹果
- 项目：[https://github.com/yuluoos/TVBox-tvs](https://github.com/yuluoos/TVBox-tvs)

### 1.5 默影视
- webhtv 的二次开发版，包名与原版不同可共存
- 项目：[https://github.com/Silent1566/webhtv](https://github.com/Silent1566/webhtv)
- 下载（releases）：[https://github.com/Silent1566/webhtv/releases](https://github.com/Silent1566/webhtv/releases)
- 更新非常快；带 `beta` 为测试版（如 `5.5.6-beta-202608041907`），否则为正式版（如 `5.5.6-202607201306`）

### 1.6 PeekPro
- 支持 md5 等多种源，影视二次开发版
- 前身 PeekMili（羊壳），不支持 TV，支持 iOS，功能强，类似以前的猫影视
- 已停更，旧版本 PeekMili 1.2.5 仍可用；关闭鉴权服务器，网上多为篡改版本
- Mac / Win 支持 `t4`、`.md5`；安卓还支持 tvbox 格式，运行 php 需安装 php
- iOS 不支持 PHP、py 脚本及本地包
- 巨魔安装：先用全能签签名打开文件访问，再巨魔安装
- 项目：[https://github.com/ingriddaleusag-dotcom/PickTV](https://github.com/ingriddaleusag-dotcom/PickTV)
- 下载：[https://github.com/ingriddaleusag-dotcom/PickTV/releases](https://github.com/ingriddaleusag-dotcom/PickTV/releases)

### 1.7 iOS 专用

#### 1.7.1 应用商店
- App Store：[https://apps.apple.com/](https://apps.apple.com/)
- **JS TV**：想要最大灵活度和脚本能力，国内可搜到，支持 md5 接口，高级功能付费
- **Hawk Player**：想要全能播放器，国内可搜到，支持 md5 接口，高级功能付费

#### 1.7.2 Miraplay（魔力云播）
- 专门的猫爪源播放器，需外区 ID，高级功能付费，苹果 App Store 上架
